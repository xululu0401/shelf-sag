# 摆书前压一压

层板放满书，放久了会弯多少、看不看得出来；不过关的给出加支撑、换厚板、贴木条、少放书四条改法。

- 体验：https://xululu0401.github.io/shelf-sag/
- 单文件静态页：`index.html` + `core.js`（纯计算）+ `ui.js`（界面），不联网、不收集数据，输入只存在浏览器 localStorage。
- 测试：`node --test tests/core.test.cjs`（锚点由独立的 Python 精确有理数脚本给出，见批次目录 evidence/手算锚点.py）。
- 模型：均布荷载梁 δ = k·w·L⁴/(384EI)，k = 5（搁着）/ 1（两端钉死、无中间支撑）；前封边木条按换算截面；长期 = 刚放上 × (1 + 蠕变系数)。
- 默认场景虚构；材料 E、蠕变系数、上限都是可改的设计值，不是实测或规范。只算变形，不算强度与连接件承载。
